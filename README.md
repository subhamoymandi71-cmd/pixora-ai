# PIXORA AI — Starter Flutter Project

This is the first UI prototype for PIXORA AI. It includes a dark premium home screen and placeholder feature cards.

## Important
- This starter is a user-interface prototype only.
- Text-to-video, image-to-video, AI voice, login, credit billing, and cloud storage are NOT connected yet.
- Real AI video generation requires a backend and a licensed AI video-generation API. Keep API keys on the backend; never place secret keys in the Android app.

## Run with Flutter
1. Install Flutter SDK on a computer or use a supported cloud development environment.
2. Open this project folder.
3. Run `flutter pub get`
4. Run `flutter run`

The main screen is in `lib/main.dart`.
